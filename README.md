# Monad 链练习（Blitz 赛前）

本目录是 **Monad Blitz @惠州** 的本地练习场，不是作业仓库副本。

| 路径 | 用途 | 谁来建 |
|---|---|---|
| `docs/` | 计划、笔记 | 已放好 |
| `01-counter/` | 第 1 天：第一个上链合约 | 你在里面 `forge init .` |
| `02-bank/` | 第 2 天：自己写 Bank | 你在里面 `forge init .` |
| `03-product/` | 第 3 天或赛前：真正拿去 Demo 的产品 | 进展够了再 `forge init .` |
| `secrets/` | 本地密钥备忘（可选） | 已 gitignore，不要提交 |

原则：练习在 `01`/`02`，现场产品在 `03`。不要把 Bank 原样当黑客松项目。

从这里开始：打开 `docs/Monad-Blitz-赛前准备计划.md` 第 1 天。
